# Official Godot 4.7 documentation

Use Godot 4.7 documentation for version-sensitive facts. Fetch raw reStructuredText when a class page is too large:

```text
https://docs.godotengine.org/en/4.7/_sources/<page>.rst.txt
```

Class filenames are lowercase (`classes/class_characterbody3d.rst.txt`). Verify exact signatures, defaults, enums, annotations, and virtual callbacks instead of recalling them. In class RST, member anchors use the original class casing, such as `_class_CharacterBody3D_method_move_and_slide:`.

Use the installed engine's documentation when a Game Project pins a different version. Do not silently upgrade project files or APIs.
