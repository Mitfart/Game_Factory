# Input — Godot 4.7

Poll `Input` for held state and use the callback event for transitions. Gameplay normally belongs in `_unhandled_input()` so GUI handles events first. Keep built-in `ui_*` actions for interface navigation. Runtime `InputMap` edits are not persisted automatically.
