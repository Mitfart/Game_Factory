# Export

1. **Inspect:** Read project version, target platform, renderer/features, export presets/templates, included files, and secret/signing requirements. Read [export.md](../../references/godot-4.7/export.md).
2. **Change:** Implement only the inspected target preset and required project compatibility change using the loaded reference.
3. **Verify:** Produce a release export, launch it on the target, exercise the required path, and inspect logs. For Web, test served output at target viewport/input modes and required hosting headers.
