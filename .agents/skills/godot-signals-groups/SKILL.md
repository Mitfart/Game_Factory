# Signals and groups

1. **Inspect:** Trace emitters, connections, callback lifetimes, deferred paths, group membership, and every consumer. Read the signals/groups sections of [language.md](../../references/godot-4.7/language.md).
2. **Change:** Implement only the inspected signal, connection, or group change using the loaded reference.
3. **Verify:** Exercise connect, emit, scene removal/reload, deferred/one-shot behavior, and empty or mixed groups; inspect duplicate callbacks and runtime diagnostics.
