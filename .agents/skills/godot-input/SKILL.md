# Input

1. **Inspect:** Read Input Map actions, callback routing, Control mouse filters, focus neighbors, and all callers of the affected action. Read [input.md](../../references/godot-4.7/input.md) and UI focus details in [ui-localization.md](../../references/godot-4.7/ui-localization.md) when Controls are involved.
2. **Change:** Implement only the inspected action, routing, focus, or pointer change using the loaded references.
3. **Verify:** Test keyboard, pointer, and configured controller/touch paths; test mouse-free focus traversal for UI; inspect duplicate handling and runtime diagnostics.
