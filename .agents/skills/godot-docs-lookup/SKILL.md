# Look up Godot documentation

1. **Inspect:** Identify the project's Godot version and the exact class, member, or behavior in question.
2. **Lookup:** Follow [official-docs.md](../../references/godot-4.7/official-docs.md). Prefer the pinned official class/tutorial source and extract only the relevant member or section.
3. **Verify:** Compare the result with the project version and usage site; report the exact source URL. A missing page is a rename/version signal, not permission to guess.
