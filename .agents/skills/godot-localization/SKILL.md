# Localization

1. **Inspect:** Locate source strings, translation catalogs/domains, locale settings, formatting, fonts, and layout-direction overrides. Read [ui-localization.md](../../references/godot-4.7/ui-localization.md).
2. **Change:** Implement only the inspected message, catalog, locale, font, or layout-direction change using the loaded reference.
3. **Verify:** Test the source locale, one translated locale, pseudolocalization/expansion, and an RTL path when supported; inspect missing glyphs, clipping, focus order, and directional icons.
