# TileMapLayer

1. **Inspect:** Read the `TileSet`, source IDs/atlas coordinates, layer settings, terrain/custom-data definitions, and all cell mutation callers. Read [tilemap-2d.md](../../references/godot-4.7/tilemap-2d.md).
2. **Change:** Implement only the inspected layer, cell, terrain, custom-data, navigation, or collision change using the loaded reference.
3. **Verify:** Reload the scene, inspect representative cells and terrain joins, then exercise applicable collision, navigation, scene-tile, and Y-sort behavior without parser/runtime errors.
