# Audio

1. **Inspect:** Read audio stream imports, players, bus routing/effects, overlap requirements, listener placement, volume controls, and pause behavior. Read [audio.md](../../references/godot-4.7/audio.md).
2. **Change:** Implement only the inspected player, stream, bus, effect, or volume change using the loaded reference.
3. **Verify:** Listen through the playable path, test overlap, looping, pause/resume, bus sliders, and 2D/3D attenuation that apply; inspect missing streams and runtime warnings.
