# Later `/gf-prototype` runs

Read this file whenever `dev`, a prior run record, or prior Prototype branches show that this is not the first run.

1. Ask the Operator to explicitly state the reviewed-run disposition: `continue prototyping`, `select <prototype branch>`, or `stop`, with free-form feedback.
2. Record that disposition and feedback on `dev` before dependent work. Silence is never a verdict.
3. Proceed with this skill only for `continue prototyping`. Selection belongs to the future `/gf-dev-cycle`; `stop` preserves all work and ends without a new run.
4. Use current `dev` as the baseline, never a prior Prototype branch. Preserve all earlier branches, worktrees, `PROTOTYPE.md` files, and evidence unchanged.
5. Revise `PROTOTYPE_SPACE.md` from feedback and obtain explicit approval; Git preserves its prior version.
6. Give the run a new descriptive identity. If the Operator explicitly requests one synthesis, treat it as a new hypothesis from current `dev`; transfer approved ideas selectively without merging old Prototype branches.
