# Godot UI

1. **Inspect:** Read the Control ancestry, containers, anchors/offsets, size flags, minimums, focus paths, theme inheritance, and target viewport sizes. Read [ui-localization.md](../../references/godot-4.7/ui-localization.md).
2. **Change:** Implement only the inspected layout, sizing, focus, or theme change using the loaded reference.
3. **Verify:** Test narrow/wide and scaled viewports, mouse-free navigation, pointer use, long/pseudolocalized text, RTL when relevant, and theme changes without clipping or overlap.
